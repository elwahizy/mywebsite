# My Website - Layout Master

A modern, responsive website template featuring a clean design with CSS Grid layout.

## Features

- Responsive navigation bar with sticky positioning
- CSS Grid-based image gallery
- Multiple pages (Home, About, Jobs, Contact)
- Modern color gradients and hover effects
- Mobile-friendly design

## Pages

- **index.html** - Main landing page with image gallery
- **about.html** - Information about the company
- **jobs.html** - Career opportunities listing
- **contact.html** - Contact information

## Technologies Used

- HTML5
- CSS3 (Flexbox & Grid)
- JavaScript

## How to Use

Simply open `index.html` in a web browser or serve the files using a local web server.
