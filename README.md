# My Website

A modern, responsive website showcasing a clean layout design with a navigation menu, hero section, and grid-based content display. This project demonstrates fundamental web development concepts using HTML and CSS.

## 🚀 Features

- **Responsive Navigation Bar**: Sticky navigation menu that stays at the top while scrolling
- **Hero Section**: Eye-catching cover image with flexbox centering
- **Grid Layout**: Responsive grid system that automatically adjusts to different screen sizes
- **Smooth Animations**: Hover effects and transitions for enhanced user experience
- **Mobile-Friendly**: Responsive design with media queries for mobile devices
- **Multiple Pages**: Includes Home, About, Contact, and Jobs pages

## 🛠️ Technologies Used

- **HTML5**: Semantic markup and structure
- **CSS3**: Modern styling with:
  - Flexbox for layout
  - CSS Grid for responsive content arrangement
  - Linear gradients for colorful backgrounds
  - Box shadows and transitions for visual effects
  - Media queries for responsive design

## 🚦 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A text editor (VS Code, Sublime Text, etc.) for modifications

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/elwahizy/mywebsite.git
   ```

2. Navigate to the project directory:
   ```bash
   cd mywebsite
   ```

3. Open `index.html` in your web browser:
   - Double-click the file, or
   - Right-click and select "Open with" your preferred browser, or
   - Use a local development server

### Using a Local Development Server (Optional)

For a better development experience, you can use a local server:

**Using Python:**
```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

**Using Node.js (with http-server):**
```bash
npx http-server
```

Then open your browser and navigate to `http://localhost:8000`
